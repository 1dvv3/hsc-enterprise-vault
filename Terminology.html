📖 Terminology — Enterprise Computing

Definitions only. Nothing else in this file. ✅ = named topic in the Trial · ⚠️ = Year 11 assumed knowledge Full notes: Data Science · Intelligent Systems · Data Visualisation · Enterprise Project · Principles of Cybersecurity

A

Term Definition
Abstraction Focusing on important details while ignoring irrelevant information, to reduce unnecessary complexity
Acceptance testing Testing in which the client confirms the system meets their requirements
Active data collection Data collected intentionally from users — surveys, forms, questionnaires, input fields
Actuator A device converting electrical control signals into physical motion; includes servo, stepper and DC motors
Aggregation Combining many data values into one summary value — sum, average, count, median
Agile An iterative and incremental development approach expecting requirements to change, delivering working software each cycle
Algorithm A step-by-step set of instructions for solving a problem or performing a task
Alternative data Non-traditional feedback signals from a different format or source — likes, emoticons, memes, click counts, sentiment labels
Australian Privacy Principles (APPs) The 13 principles in the Privacy Act 1988 governing collection, use, disclosure, governance, accountability, integrity and correction of personal information, and individuals' right of access
Availability Ensuring authorised users can access information and services when needed

B

Term Definition
Backward chaining Goal-driven reasoning — starts with a hypothesis and works backward to check whether the facts support it
Beta testing Release to a limited group of real users outside the development team, before full release
Bias Systematic unfairness in data arising from how it is collected, processed or interpreted; leads to skewed results and discrimination
Big data Datasets characterised by volume, velocity, variety, veracity and value, too large or complex for traditional systems
Biometrics Technology measuring human physical or behavioural characteristics — fingerprint, face, voice — for identification and authentication
Blockchain A distributed ledger managing and verifying data securely and decentrally, where each block contains the hash of the previous block
Bot An automated program performing tasks without human intervention
Botnet A network of compromised machines controlled remotely, used for DDoS attacks or spam
Boundary data Test data at the edges of the valid range

C

Term Definition
Certainty factor A confidence value attached to a rule or conclusion, letting a system express how sure it is rather than a flat yes/no
Cloud storage Data stored on remote servers accessed over the internet — scalable and accessible, but internet-dependent
Communicated data Data presented with context and explanation — sample size, timeframe, limitations. Informative rather than persuasive
Composite key Two or more fields together forming a primary key, typically in a join table
Computational thinking Problem-solving through decomposition, pattern recognition, abstraction and algorithms
Confidentiality Protecting sensitive data from unauthorised access, exposure or theft
Consumer Data Right (CDR) Australian framework mandating data handling with consumer consent in designated sectors such as banking and energy
Correlation A relationship where two variables move together — does not prove causation
Curated data Data that has been selected, with context removed and the message simplified for impact. Persuasive rather than informative

D

Term Definition
Dashboard A single screen bringing together a small set of metrics with enough context to support a decision
Data bias Systematic errors from selective sampling, underrepresentation of groups or measurement error
Data cleaning Removing duplicates, fixing missing values and correcting errors
Data dictionary Documentation of a database's structure — field names, data types, formats and attributes
Data filtering Selecting relevant data and discarding surplus or unnecessary data
Data flow diagram (DFD) A diagram showing how data moves through a system, comprising external entities, processes, data stores and data flows
Data integrity The accuracy, completeness and trustworthiness of data, assessed through ownership, source, validation, risk, scope and depth of insight
Data lake A repository storing raw data in multiple formats using schema-on-read
Data literacy The ability to read, interpret and question data — determines whether data informs or merely influences
Data mining Discovering patterns, relationships and anomalies in large datasets
Data sampling Selecting a subset of data from a larger dataset so decisions can be made efficiently
Data sovereignty The right of a people — particularly Aboriginal and Torres Strait Islander Peoples — to control the collection, ownership and application of data about them
Data swamp Too much unorganised, undocumented or irrelevant data, making useful information hard to find
Data validation Checking data meets specific rules and standards
Data warehouse A central repository storing large volumes of historical and current data from multiple sources, structured for analysis
Decision support system (DSS) An interactive computer-based system helping people make decisions by analysing large datasets, combining data, analytical models and user-friendly software
Decision tree A model breaking decisions into simple IF–THEN steps, where branches are conditions and leaves are outcomes
Decomposition Breaking a complex problem into smaller, manageable parts
Design thinking A human-centred process: empathise, define, ideate, prototype, test
DDoS Distributed denial of service — flooding a service with traffic to deny availability
Dicing An OLAP technique analysing a subset of data across multiple dimensions
Direct implementation The old system is switched off and the new one on across the whole organisation at once. Highest risk, cheapest
Drill-down An OLAP technique breaking summary data into more detailed levels

E

Term Definition
End-user development The users themselves develop the system, typically with spreadsheets or low-code tools
Enterprise data warehouse (EDW) An organisation-wide data warehouse combining historical and real-time data
Errors Mistakes made in data collection, entry or processing
Evil twin A fake or impersonated account made to look like a real person or brand
Expert system A system mimicking a human expert in a specific domain, comprising a knowledge base, inference engine and user interface
Exploit The act of illegally accessing systems, networks or data by taking advantage of a vulnerability
External entity In a DFD, a source or sink of data — a user or sensor. Named with a noun

F

Term Definition
Factual knowledge Knowledge widely shared through textbooks and resources, agreed upon by experts
Flat-file database Data stored in a single table or file — plain text, CSV or JSON — without relationships or indexing
Flowchart A diagram representing logic and decision-making, read top to bottom and left to right
Foreign key A field referring to a primary key in another table, creating the relationship between them
Forward chaining Data-driven reasoning — starts with known facts and applies rules to derive conclusions
Functional testing Verifying that every function performs according to its specification
Fuzzy logic Reasoning that is approximate rather than precise, handling uncertainty and imprecision

G

Term Definition
Gantt chart A project management tool scheduling tasks, milestones and deadlines, showing concurrent activities
GDPR The EU's General Data Protection Regulation, built on 7 fundamental principles

H

Term Definition
Haptics Technology using touch, vibration or motion feedback to simulate physical interaction
HAVING An SQL clause filtering groups after GROUP BY, as distinct from filtering rows
Heuristic knowledge Practical "rules of thumb" obtained through experience and reasoning rather than formal proof
Hypothetical reasoning Exploring "what-if" scenarios by testing different hypotheses to determine possible outcomes

I

Term Definition
ICIP Indigenous Cultural and Intellectual Property — the right of Indigenous communities to control their cultural heritage, traditions and knowledge
Industry 4.0 The integration of automation, data exchange and intelligent systems into manufacturing and enterprise
Inference engine The component of an expert system applying rules to the knowledge base and user input to reach a conclusion
Infographic A visual simplifying complex processes for easy understanding; a static, single-point-in-time dashboard qualifies
Informatics The study of the processing and management of information, transforming raw data into knowledge
INNER JOIN An SQL join returning only rows with matches in both tables
Integrity (of information) Maintaining the accuracy, consistency and reliability of data
Intelligent agent A system acting on behalf of a user; simplistic agents follow fixed rules, complex agents learn and adapt
Intelligent system A system that learns, adapts and reasons under uncertainty, rather than following static rules
Interval A level of measurement with ordered, equal gaps but no true zero — temperature in °C, calendar years
IoMe Internet of Me — personalised, individual-centred connected services and data
IoT Internet of Things — networked physical devices collecting and exchanging data
Iterative approach Building in repeated cycles, refining with each pass rather than completing everything once

J–L

Term Definition
Join table A table resolving a many-to-many relationship by holding foreign keys to both original tables
Knowledge base The component of an expert system storing domain facts and rules
LEFT JOIN An SQL join returning all rows from the left table, whether or not they match
Level 0 DFD A context diagram showing the whole system as one process with its inputs, outputs and external entities
Level 1 DFD A DFD breaking the main process into sub-processes
Limitations Inherent constraints of data — sample size, coverage, representativeness, or the scope of the sources
Live data testing Testing with real, current operational data
Local storage Data stored on a single local machine — fast and controlled, but limited in scalability

M

Term Definition
Machine learning Algorithms identifying patterns and relationships in large datasets, improving with more data
Metadata Data about other data — how, when and by whom it was collected
Microcontroller A compact integrated circuit containing CPU, memory and I/O ports, performing specific control tasks in an embedded system
Multi-factor authentication (MFA) Requiring two or more independent factors to verify identity

N–O

Term Definition
Nominal A level of measurement using named categories with no order — eye colour, suburb
Normalisation Structuring a database to reduce redundancy and improve efficiency, consistency and accuracy
NoSQL A flexible database type storing and integrating multiple data formats without a strict schema
Notifiable Data Breaches (NDB) scheme Requires entities to notify affected individuals and the OAIC about breaches likely to result in serious harm
OAIC Office of the Australian Information Commissioner — the authority enforcing the Privacy Act
OLAP Online analytical processing — software analysing large, multi-dimensional datasets organised in a cube structure
Ontology classification Organising knowledge into categories and concepts and defining the relationships between them
Ordinal A level of measurement using categories with a meaningful order but unequal gaps — satisfaction ratings, year level
Outlier A data point very different from the rest; may indicate an error or a valid unusual event
Ownership (data integrity) Who controls and maintains data, and therefore who is accountable for its accuracy

P

Term Definition
Parallel implementation Old and new systems run together for a period. Lowest risk, most expensive
Passive data collection Data collected automatically, without direct user input — logs, sensors, clickstream, analytics
Pattern recognition Identifying recurring patterns or trends in data or processes
Phased implementation The system introduced one module or department at a time
Phishing Deceptive messages or links tricking users into revealing private information. By SMS it is smishing
Pilot implementation The system trialled with a small group of users first
Pivot table An interactive spreadsheet tool summarising and exploring large datasets without formulas
Predictive analytics Using models and machine learning to identify patterns and forecast future trends
Primary data Data collected directly by you for a specific purpose
Primary key A field uniquely identifying each row; cannot be null or duplicated
Privacy The individual's right to control their personal information
Privacy Act 1988 (Cth) The primary Australian law governing how personal information is collected, used, stored and disclosed
Processed data Data cleaned, transformed or manipulated to make it easier to analyse
Prototyping Building a working model early and refining it based on feedback

R

Term Definition
Ratio A level of measurement with ordered, equal gaps and a true zero — height, weight, price
Raw data Data that has not been processed or analysed in any way
RDBMS Relational Database Management System — stores data in multiple linked tables, reducing duplication
Relevance Whether data is appropriate to the purpose it is being used for
Reliability Whether the same results would be obtained if the data were collected again
Risk The potential for harm when a threat exploits a vulnerability
Risk analysis Identifying what could go wrong in a project so risks can be prevented or mitigated
Roll-up An OLAP technique combining detailed data into a higher-level summary

S

Term Definition
Secondary data Data collected by someone else and used by you for analysis
Semi-structured data Data with some organisational properties but no strict schema — JSON, XML
Semi-structured decision A decision where some elements can be automated but judgement is still required; the system recommends, a human decides
Sensor A device detecting and measuring physical conditions and converting them into digital signals
Simulated data testing Testing with artificially generated data, including edge cases
Slicing An OLAP technique selecting a single layer of the cube by filtering one dimension
Smishing Phishing conducted via SMS
Structured data Data organised in a fixed format — rows, columns, fields
Structured decision A routine, repetitive decision with clear rules; the system decides and acts without human involvement
Surplus data Redundant or unnecessary data that wastes storage and causes lag

T–U

Term Definition
Threat An individual or group carrying out cyberattacks, or the potential source of harm
Truth maintenance system (TMS) Tracks which facts are true in a dynamic environment and consistently updates related facts when information changes
Uncertainty Lack of precision or ambiguity in data, arising from measurement, the nature of the data, or the analysis method
Unstructured data Data with no fixed format and variable length — text, images, video, memes
Unstructured decision A novel, complex decision with no clear procedure, depending on experience, intuition and negotiation
User interface The component allowing a user to enter data and receive output

V–W

Term Definition
Validity Whether data measures what it is supposed to measure
Value (big data) The real-world benefit an organisation obtains from its data
Variety (big data) The many different formats data takes — structured, semi-structured and unstructured
Velocity (big data) The speed at which data flows into a system
Veracity (big data) The accuracy and reliability of data
Verification Confirming the system is built right — that it meets its specifications
Validation (systems) Confirming the right system was built — that it meets the user's actual needs
Volume (big data) The massive amount of data generated and stored
Volume testing Testing with large quantities of data to check performance under load
VPN Virtual Private Network — encrypts data before transmission over an untrusted connection
Vulnerability A weakness in a system or process that an attacker can take advantage of
Waterfall A linear, sequential development approach where each phase completes before the next begins
Webometrics The measurement and analysis of web data, used to keep systems updated with real-time information
WHERE An SQL clause filtering individual rows, before grouping
What-if modelling Changing inputs in a spreadsheet to observe the effect on outputs — scenario testing

The Ten Most Confused Pairs

vs
Curated data — selected, context removed ↔ Communicated data — context included
Data warehouse — structured, documented ↔ Data swamp — unmanaged accumulation
Forward chaining — starts with facts ↔ Backward chaining — starts with a goal
Knowledge base — holds facts ↔ Inference engine — applies rules
Slicing — one dimension ↔ Dicing — multiple dimensions
Drill-down — summary to detail ↔ Roll-up — detail to summary
Verification — built right ↔ Validation — the right system
Interval — no true zero ↔ Ratio — has a true zero
Validity — measures what it should ↔ Reliability — repeatable results
Pilot — small group first ↔ Phased — one module at a time
